# 一周试用清单

目标：邀请 10–20 位习惯原 Launchpad 的 Mac 用户，自愿试用七天。此文件是试用方案，不代表已经完成招募或获得反馈。

## 首次使用

- 从 DMG 安装并打开，设置合适的快捷键和登录项。
- 在不看说明的情况下找到并打开三个指定应用，记录耗时和困惑。
- 只用键盘搜索、选择和打开一个应用；测试中文输入法组词。
- 创建文件夹、整理至少五个应用；退出/重启后确认布局保留。
- 导出布局，调整后再导入，确认能恢复；若没有旧数据库，记录可理解的提示。

## 日常使用

- 每天是否继续使用 LaunchGrid？为何改回系统入口或其他工具？
- 新安装/删除应用是否自动更新？别名、拼音与首字母是否符合预期？
- 运行状态/网络详情是否解决了具体问题？记录任务，不上传完整连接列表。
- 剪贴板开关、暂停、忽略应用和清空是否清晰？不用复制真实凭据做测试。
- 是否出现误抢键、窗口焦点问题、发热或后台采样？提供复现步骤。

## 第七天回访

记录匿名编号、设备架构/macOS/应用版本、使用天数、主要入口、保留或卸载原因、最常用模块、前三个问题。不开启遥测、不自动上传历史；由参与者选择提交到 Issues 的内容。

下一版按持续使用和具体问题排序；仅测试通过不能推断产品留存率。
