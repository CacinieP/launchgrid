# LaunchGrid 0.4.2

用熟悉的图标启动应用，快速查看它的运行与联网状态。

- 应用网格加入方向键导航与回车启动，兼顾搜索框编辑和输入法组词。
- 拖放排序、单层文件夹、自定义搜索别名与本机布局持久化；支持 JSON 备份/恢复与只读导入仍存在的旧 Launchpad 数据库。
- 搜索支持中文拼音、首字母、别名和全半角；应用安装/卸载自动更新清单。
- 应用右键可查看本体和子进程的 CPU、内存、速率与可见网络连接，并请求正常退出。
- 设置提供五组可录制快捷键、系统冲突反馈、登录时启动与模块开关。
- 剪贴板新安装默认关闭；支持启用/关闭、暂停/恢复、忽略指定应用并移除旧记录、确认清空。恢复不会补录停用期间的文本。
- 网络采样只在可见面板/应用详情内运行，关闭或隐藏后丢弃过期结果；重新开启不计入停用期间流量。
- 每日可选版本检查；点击后下载并验证官方资产 SHA-256、App 标识/版本、签名 Team 与 Gatekeeper，安装后可重启。
- **许可证从本版本起改为 AGPL-3.0-only**。App 附带完整许可证及确切源码链接，Release 附对应源码包和 SHA-256 清单。
- 增加英文使用说明、反馈模板及试用清单。

## 安装

下载 `LaunchGrid-0.4.2.dmg`，拖入 Applications 后打开。支持 macOS 26+、Apple Silicon 和 Intel。正式包使用 Developer ID 签名并经过 Apple 公证。

默认快捷键沿用 F4 / ⌥F4 / ⇧F4 / ⇧⌥F4 / ⌘F4，可在菜单栏「设置…」修改。新用户的剪贴板采集默认关闭；已有剪贴板历史的升级用户延续原开启状态，设置中会显示说明。

## 边界

旧布局恢复需要仍可读取、结构受支持的 Apple 数据库，只匹配已安装应用。剪贴板仅纯文本，在本机以明文 JSON 存储、权限 0600、保留七天/最多200条；敏感标记依赖来源应用，来源按前台应用估计。应用状态按路径和父子进程归因，连接可见性受系统权限限制。更新不包含启动失败后的自动回滚。

真实用户的一周试用仍需持续收集；自动化测试和本机验收不等同于长期用户验证。
