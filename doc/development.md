## 环境与构建

需要 macOS 和提供 Swift 6.x 的 Xcode/Swift 工具链。包的 tools-version 为 5.9，`Package.swift` 声明 macOS 13 部署基线；发行 App 的 `Resources/Info.plist` 明确要求 **macOS 26.0+**，两者含义不同。项目是单个 Swift Package，没有第三方 package 依赖，使用系统 AppKit、SwiftUI、Combine、Carbon 等框架。

在仓库根目录运行：

```bash
swift build
swift test
./scripts/make_app.sh
```

打包脚本默认构建 `arm64` + `x86_64` 通用二进制，产出仓库根目录的 `LaunchGrid.app`，并替换此前同名构建目录。默认 ad-hoc 签名；仅本机开发构建可运行：

```bash
UNIVERSAL=0 ./scripts/make_app.sh
```

App 会包含 `LICENSE`、源码 commit 和源码链接。对应源码 commit 必须与构建内容一致，供分发的包应从干净、已合并的 commit 构建。Developer ID 签名、公证和 DMG 流程见 [发布流程](releasing.md)。开发包复制进 Applications 会替换同名安装，应在确定需要时手动操作。

## 验证方式

[CI](../.github/workflows/ci.yml) 在 PR 和 main push 上运行 debug build、`swift test`、release build。测试位于 [Tests/LaunchGridTests](../Tests/LaunchGridTests/)：

| 文件 | 验证范围 |
|---|---|
| `LaunchGridTests.swift` | 字节格式、接口/端点解析、进程派生字段、剪贴板预览 |
| `LauncherTests.swift` | 搜索与导航、布局操作/恢复、目录扫描、旧数据库导入 |
| `ClipboardControlTests.swift` | 注入独立偏好/私有 pasteboard/临时路径，覆盖开关、暂停、排除、清理与保存顺序 |
| `SettingsTests.swift` | 偏好迁移、快捷键验证与冲突保留 |
| `AppActivityTests.swift` | 按包路径和父子 PID 归因，避免相似名称混入 |
| `UpdateCheckerTests.swift` | 版本、资产 URL、摘要及隔离安装场景，具体覆盖以测试源码为准 |

这些是验证入口与范围，本文不记录某次测试通过数量。自动化通过仍需补真实键盘/输入法、布局拖放、权限、登录项、签名包安装与更新验收；一周用户留存与体验按 [试用清单](USER_TESTING.md) 另行收集。

## 调试启动与截图

直接执行目标 App 的二进制可传入环境变量，避免 `open` 复用已运行进程时变量不生效。先从菜单退出其他 LaunchGrid 实例；仅在需要时启动调试实例。

```bash
LAUNCHGRID_SHOW_ON_LAUNCH=apps ./LaunchGrid.app/Contents/MacOS/LaunchGrid
```

不依赖屏幕录制的截图来自 App 自己的视图渲染：

```bash
LAUNCHGRID_SHOW_ON_LAUNCH=network LAUNCHGRID_NETWORK_TAB=traffic LAUNCHGRID_SNAPSHOT_PATH=/tmp/launchgrid-network.png LAUNCHGRID_SNAPSHOT_DELAY=5 ./LaunchGrid.app/Contents/MacOS/LaunchGrid
```

| 变量 | 含义 |
|---|---|
| `LAUNCHGRID_SHOW_ON_LAUNCH` | `apps` / `processes` / `clipboard` / `network`，启动时显示该面板 |
| `LAUNCHGRID_PRESENTATION` | `fullscreen` / `window`，覆盖本次调试呈现方式 |
| `LAUNCHGRID_NETWORK_TAB` | `traffic` / `connections` / `dns` / `diagnostics` |
| `LAUNCHGRID_SNAPSHOT_PATH` | PNG 路径；不设不截图 |
| `LAUNCHGRID_SNAPSHOT_DELAY` | 截图延迟秒数，默认 2；采样画面可适当延后 |
| `LAUNCHGRID_AUTORUN_DIAGNOSTICS` | `1` 时进入诊断页自动检查，会发送真实网络探测 |

Debug 默认写 `/tmp/launchgrid-debug.log`，Release 默认不写。需要时开启后重启应用，用完关闭；日志并不自动轮转。

```bash
defaults write app.caciniep.launchgrid launchgrid.debugLog -bool YES
defaults write app.caciniep.launchgrid launchgrid.debugLog -bool NO
```

截图可能含应用清单、剪贴板或连接信息。仓库截图应只使用可公开的测试内容；不要在测试中采集用户真实剪贴板或替换真实安装。

## 采样与功能细节

应用清单递归扫描 `/Applications`、`/System/Applications`、`~/Applications`；系统 Utilities 因递归包含在内。目录深度有限制，不继续进入 `.app` 内部；路径去重后按名称排序。目录事件延迟合并触发重扫，安装/移除时清掉图标缓存。网格每页 5 行、3–7 列，窗口最小 780×480；全屏通常为 7 列。布局和别名独立于安装清单保存。

进程通过 `/bin/ps -axww` 获取 PID、父 PID、用户、CPU%、内存、状态和完整 `comm` 路径，约每 2 秒刷新。CPU 是系统衰减平均值，不能当作瞬时占用。搜索支持名称/路径/PID，表头切换排序；正常终止优先通知 GUI App 自行退出，其余 SIGTERM，强制终止为 SIGKILL。操作其他用户/root 进程可能因权限失败。

剪贴板启用后每 0.6 秒检查 `changeCount`；仅收纯文本，上限 256 KiB/条、200 条，重复文本提到最新。跳过 `ConcealedType`、`AutoGeneratedType`、`TransientType`，但标记依赖来源 App。启动/恢复设置新基线，不补录此前剪贴板。载入/面板出现及采集期间按日清理过期条目；排除来源也删除历史匹配记录。保存延迟合并 1.5 秒，删除/清空立即排队，单队列保证写入顺序，退出时等待写完。

直接回贴的目标在呼出界面前捕获，避免取到 LaunchGrid 自己。收起后激活目标，等待约 0.3 秒，仅在目标仍为前台时发 ⌘V。窗口持续显示时再次切换其他 App 不会实时追踪每个输入位置；没有辅助功能权限时使用「仅复制」。

整机流量用 `netstat -b -I <默认接口>` 计数器与单调时钟差分，首次/重启采样无基线时显示 0。约每 2 秒实时刷新；`nettop -P -d ... -L 2 -s 1` 取约 1 秒增量，`ps` 补完整名称。连接使用 `lsof -i -n -P`，而不是把 `netstat -an` 与 lsof 拼接；旧观察表明前者的连接段在某些非 shell 启动环境缺失。共享端点仍保留各 PID/协议的归属，权限可见范围依系统而定。

网络历史每 5 秒追加 JSONL，近 5 分钟曲线来自内存样本；日/周/月累计只反映采样时段，不代表全天完整用量。DNS 读 `scutil --dns`，失败回退 `/etc/resolv.conf`；写入使用 networksetup 的**服务名**而不是 en0 这类接口名，服务名通过硬件端口/设备/MAC 信息匹配。IPv6 地址解析保留完整地址。

DNS 探测向指定服务器发送实际 A 查询，显示延迟、成功率和失败数。诊断包括网关/外网连通性、IP 配置、DNS 解析、丢包/抖动；修复建议可刷新 DNS、切换 DNS、续 DHCP、重置适配器、重置网络栈或切换 IPv6。界面会显示修复动作的影响说明，可能需要管理员授权。`NetworkTools` 还实现公网/本地地址、GeoIP、双栈查询，当前没有独立 IP 信息界面。

普通命令使用参数数组；提权通路通过受约束的 AppleScript shell 执行，输入校验与引用见 `Shell.swift` / `NetworkTools.swift`，不能笼统视为“所有通路均不经过 shell”。App 未启用 Sandbox；系统子进程和网络设置是明确的能力边界。

## 图标与维护

图标由 AppKit 绘制脚本生成；以下会更新资源文件：

```bash
swiftc -O scripts/make_icon.swift -o /tmp/launchgrid-genicon
/tmp/launchgrid-genicon /tmp/LaunchGrid-AppIcon.iconset
iconutil -c icns /tmp/LaunchGrid-AppIcon.iconset -o Resources/AppIcon.icns
```

代码变更走 feature branch → PR → GitHub merge；发布前完成 diff 自审、CI 和必要实机验收。从已合并 commit 生成正式构建，避免包内源码链接与实际二进制不一致。签名、公证、源码分发和可重复执行边界见 [发布流程](releasing.md)。
